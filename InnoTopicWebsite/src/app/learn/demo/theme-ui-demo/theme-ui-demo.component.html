Stencil Theme Demo

@innotopic/theme-ui

The two custom elements below - <theme-selector> and <theme-configurator> - are used directly here, with no Angular wrapper in between. Both read and write the same theme store, so changes made in one show up live in the other, and everywhere else on the site.

<theme-selector>

Presets, including the Neumorphism and Neubrutalism corner/shadow looks.

<gradient-shadow>

From @innotopic/gradient-shadow-ui - wraps any shape or text in a shadow that sweeps from the primary to the secondary theme color. Change the theme above and watch these shadows shift and animate along with it.

Gradient Shadow

<animated-plasma>

From @innotopic/plasma-ui - a WebGL demoscene-style plasma effect. Not theme-driven, just a fun decorative background.

<theme-configurator>

Freeform colors, shadow, and per-corner radius - lock the padlock to keep all four corners in sync, or unlock it to set each corner independently.
