# Shirt Generator Frontend

This is the frontend application for the Shirt Generator, built with React. It provides a user interface for entering prompts and displaying relevant logos fetched from the backend.

## Features

- User-friendly interface for entering prompts.
- Displays logos based on the user input.
- Communicates with the backend service to fetch logos.

## Getting Started

### Prerequisites

- Node.js
- npm (Node Package Manager)
- Windows 10 or 11

### Setup and Run

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/shirt-generator.git
    cd shirt-generator\frontend
    ```

2. Run the setup and start script:
    ```sh
    setup_and_run.bat
    ```

3. The application will be running at `http://localhost:3000`.
